# Leo VA Portfolio — Starter

A single-page, accessible, and mobile-first website for a professional Virtual Assistant.

## How to use
1. Open `index.html` in your browser to preview.
2. Replace assets:
   - `assets/profile.jpg` with your photo (4:5 portrait).
   - `assets/favicon.png` and `assets/og-image.png`.
3. Edit copy in `index.html` sections: hero, services, case studies, about, achievements, testimonials, contact.
4. Update social/profile links in the JSON-LD script and footer.
5. Deploy on Netlify or GitHub Pages.

## Notes
- Theme toggles between dark and light (button in navbar).
- Pricing is a placeholder—adjust to your market.
- Contact form includes a `netlify` attribute for easy static hosting forms; or switch to EmailJS / serverless endpoint.
